直接内置 com4399 WebRegisterClient → 实名 → 登录，最后返回可直接使用的 SAuth Cookie（登录时可一键回填）。如果已经有账号，只需勾选「仅登录」填 user/pass 即可拿到 cookie。

🎫 FBToken（ToolDelta / NeoOmega 验证服务器用）

ToolDelta 配置 → 选择「Bunker-web 验证服务器 §a✔」→ 手动输入此处的地址；或启动时 --auth-server <auth_server_url> -T <fbtoken>。
⚠ NeoOmega 客户端默认只允许 host = localhost / 127.0.0.1 / liliya233.uk / user.fastbuilder.pro，其他 host 需修改 neomega-core 白名单或通过本地反向代理转发。
